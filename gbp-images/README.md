# GBP images — upload guide

Generated by `scripts/gbp-images.sh` from `assets-src/services/`. Not shipped
with the site (outside `public/`). Regenerate any time with:

```
bash scripts/gbp-images.sh
```

## Google's spec (what these are built to)

| Slot | This set | Google min | Google rec | Rules |
|---|---|---|---|---|
| Logo | 720×720 PNG | 250×250 | 720×720, 1:1 | JPG/PNG, ≤5 MB. Shown circle-masked. |
| Cover | 1080×608 JPG | 480×270 | 1080×608, **16:9 exact** | JPG/PNG, ≤5 MB. Crop varies by surface. |
| Photos (Exterior / At work / etc.) | 1200×900 or 1200×1600 JPG | 250×250 | 720×720+, 4:3 or 16:9 | JPG/PNG, 10 KB–5 MB. Real photos only — no text, watermark, heavy filter, or stock. |

Every file here is JPG/PNG, well under 5 MB, above the recommended resolution.

**Filenames don't carry to Google** — GBP strips the name (and EXIF/geotag) on
upload. The names here are for our own filing; they won't help rankings. What
*does* matter: uploading each to the right category, and steady cadence
(a few photos a week beats a one-off dump).
